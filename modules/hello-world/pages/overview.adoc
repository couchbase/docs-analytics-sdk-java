= Java Analytics SDK

The Java Analytics SDK allows you to connect to an Enterprise Analytics cluster from Java.
For connecting to a Couchbase Server Cluster -- self-managed, or Capella Operational --
see our xref:java-sdk:hello-world:overview.adoc[Java Operational SDK].

TIP: Connecting to a xref:enterprise-analytics:intro:intro.adoc[_Capella_ Analytics] cluster from Java currently requires a xref:java-columnar-sdk:hello-world:overview.adoc[Java Columnar SDK].
